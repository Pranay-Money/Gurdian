🔗 Link Scanning in Webmail & Messaging
Enable Link Scanning
Analyze links in supported webmail and messaging sites (requires site permissions)
Permissions Required: Enabling specific sites below will request host permissions for those domains. You can review and grant these in the extension details page.
How it works
When enabled, Guardian scans links in your conversations on supported sites:
  • Collects only link URLs and visible text (never message content)
  • Detects display-text mismatches (e.g., "PayPal" link pointing elsewhere)
  • Shows risk badges: ● Medium, ● High/Critical
  • Intercepts clicks on High/Critical links with an unspoofable warning dialog
  • All analysis happens locally first; unknown domains checked via secure API
